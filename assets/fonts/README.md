# Blocks Pixel

`BlocksPixel-Regular.ttf` is a modified version of [Press Start 2P](https://github.com/codeman38/PressStart2P)
by The Press Start 2P Project Authors, licensed under the SIL Open Font License 1.1 (see `OFL.txt`).

It was reduced to the characters used by the game (printable ASCII and German umlauts) with
`pyftsubset` and renamed, as the license requires for modified versions using a Reserved Font Name.
